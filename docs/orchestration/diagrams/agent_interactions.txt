## Agent Interaction Patterns

### Pattern 1: Sequential Chain

```
Liquidity → Price Store → Technical → Anomaly → Correlator

Used in: Daily Analysis Workflow
Benefit: Clear data flow, easy to understand
```

### Pattern 2: Parallel Fan-Out

```
                Price Store
                     │
        ┌────────────┼────────────┐
        │            │            │
        ▼            ▼            ▼
   Technical    Anomaly      Fundamental
   (parallel)   (parallel)   (parallel)

Used in: Daily Analysis (after price sync)
Benefit: 3x faster execution
```

### Pattern 3: Validation Loop

```
   User Trade Request
          │
          ▼
   Risk Agent (validate)
          │
          ├──► Approved ──► Portfolio Agent (execute)
          │                        │
          └──► Rejected            ▼
                             Portfolio Updated
                                   │
                                   ▼
                             Risk Agent (recheck)

Used in: Validated Trade Execution
Benefit: Ensures trade safety
```

### Pattern 4: Event-Driven Cascade

```
   Anomaly Agent
          │
          │ detect high severity
          ▼
   Emit HIGH_SEVERITY_ANOMALY event
          │
          ├──► News Agent (search related news)
          │
          ├──► Technical Agent (deep dive)
          │
          └──► Correlator (correlate all data)

Used in: Automatic Investigation
Benefit: Reactive, automatic deep analysis
```

## Agent Lifecycle

```
Agent Instantiation (via AgentAdapter):

┌────────────────────────────────┐
│  AgentAdapter.load_agent()     │
│                                │
│  1. Check cache                │
│     └─ If cached, return       │
│                                │
│  2. Dynamic import             │
│     module = importlib.import_module()
│                                │
│  3. Instantiate class          │
│     agent = module.Class()     │
│                                │
│  4. Optional: inject event_bus │
│     agent.event_bus = bus      │
│                                │
│  5. Cache instance             │
│     self._cache[name] = agent  │
│                                │
│  6. Return agent               │
└────────────────────────────────┘

Agent Method Invocation:

┌────────────────────────────────┐
│  AgentAdapter.call_method()    │
│                                │
│  1. Load agent (see above)     │
│                                │
│  2. Get method                 │
│     method = getattr(agent, name)
│                                │
│  3. Call method                │
│     result = method(**params)  │
│                                │
│  4. Optional: emit event       │
│     if agent.event_bus:        │
│       agent.event_bus.publish()│
│                                │
│  5. Return result              │
└────────────────────────────────┘
```

## Agent Integration Modes

### Mode 1: Classic (No Event Bus)

```
┌─────────────────────┐
│  PSXTechnicalAgent  │
│                     │
│  def analyze(self): │
│    # analysis       │
│    return result    │
└─────────────────────┘

Called by: AgentAdapter
Events: None
Compatibility: ✓ Full backward compatibility
```

### Mode 2: Event-Enhanced (Optional Events)

```
┌──────────────────────────────────┐
│  PSXTechnicalAgent               │
│                                  │
│  def __init__(self, event_bus=None):
│    self.event_bus = event_bus    │
│                                  │
│  def analyze(self):              │
│    result = # analysis           │
│                                  │
│    if self.event_bus:            │
│      self.event_bus.publish()    │
│                                  │
│    return result                 │
└──────────────────────────────────┘

Called by: AgentAdapter (injects event_bus)
Events: Emitted if event_bus provided
Compatibility: ✓ Backward compatible
```

### Mode 3: Orchestration-Native (Future)

```
┌──────────────────────────────────┐
│  PSXTechnicalAgent               │
│                                  │
│  def __init__(self, event_bus):  │
│    self.event_bus = event_bus    │ (required)
│                                  │
│  def analyze(self):              │
│    result = # analysis           │
│    self.event_bus.publish()      │ (always)
│    return result                 │
└──────────────────────────────────┘

Called by: AgentAdapter (must provide event_bus)
Events: Always emitted
Compatibility: ⚠ Requires event_bus
```

## Summary

The 9-agent ecosystem provides:

✅ **Clear Separation** - Each agent has specific responsibility
✅ **Loose Coupling** - Agents communicate via events
✅ **Shared Data** - Single SQLite database
✅ **Parallel Execution** - Independent agents run concurrently
✅ **Event-Driven** - Reactive workflows and feedback loops
✅ **Backward Compatible** - Existing agents work unchanged
✅ **Extensible** - Easy to add new agents

Agent Count: 9
- Data Collection: 3
- Analysis: 4
- Portfolio & Risk: 2
