## Component Layers

**Layer 1: User Interface**
- CLI / Python API
- High-level workflow execution

**Layer 2: Orchestration Core**
- PSXOrchestrationAgent - Main entry point
- WorkflowCoordinator - Workflow management
- PSXEventBus - Event routing
- StateManager - Persistence

**Layer 3: Execution**
- ExecutionEngine - Task execution
- AgentAdapter - Dynamic agent loading
- Caching & retry logic

**Layer 4: Agents & Data**
- 9 specialized agents
- Shared SQLite database
- External APIs (yfinance, RSS)

## Data Flow

```
User Request
    ↓
PSXOrchestrationAgent
    ↓
WorkflowCoordinator (build DAG)
    ↓
ExecutionEngine (execute tasks in parallel)
    ↓
AgentAdapter (load & call agents)
    ↓
Agents (perform analysis)
    ↓
Results (cached & returned)
    ↓
StateManager (persist state)
    ↓
EventBus (emit events)
```

## Event Flow

```
Agent Action
    ↓
Emit Event
    ↓
EventBus.publish()
    ↓
Route to Subscribers
    ↓
Event Handlers
    ↓
Trigger Workflows (if configured)
```
